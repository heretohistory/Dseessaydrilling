# Paper 2 Essay Coach

A study website for HKDSE History Paper 2 essay questions (2012–2026).

Students choose a topic, open a past-paper question, and work through it step by step:

1. **Brainstorm & structure** – key words highlighted, what the question really asks, brainstorm points and a paragraph-by-paragraph essay plan.
2. **Guiding questions** – shown when the student clicks *Continue: I'm still stuck*.
3. **Worked example** – a sample introduction, a model body paragraph and common mistakes to avoid.

105 questions across 11 topics (Theme A, Theme B and cross-topic).

## Use it

The whole site is one file, `index.html`. Open it in any browser, or publish it free with GitHub Pages:

1. In this repository, go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
3. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

Link straight to a question with `#q2017-4` (year-question) or to a topic with `#t-ww`.

## Note

Brainstorm points, essay structures, guiding questions and sample paragraphs are study aids written for this site, not official HKEAA answers. 2026 questions have no published examiner comments yet.
